연이음

시작 단어와 끝 단어 사이를 맥락이 이어지는 단어 카드로 연결하는 캐주얼 퍼즐 게임입니다.

프로젝트 / 넥슨 게임잼 팀 프로젝트, 14팀 중 3위

역할 / 백엔드·데이터, 의미 그래프 및 판정 시스템, 튜토리얼 기획·구현, 나레이터 런타임 구현

기술 / Unity, C#, CSV, Graph, BFS, LLM-assisted Data Curation

프로젝트 개요

시작 단어와 끝 단어 사이에 손패의 단어 카드를 배치해 자연스러운 맥락을 만드는 게임입니다. 단어를 노드, 설명 없이도 직접 연결된다고 납득할 수 있는 관계를 엣지로 표현한 의미 그래프를 사전에 구성했습니다.

같은 조합에 일관된 판정을 내리고 런타임 LLM 호출 없이 빠르게 처리할 수 있도록 고정 그래프를 사용했으며, BFS로 연결 여부와 최단거리를 계산해 성공 판정과 힌트 시스템에 활용했습니다.

담당 내용

  • 단어·엣지 CSV 구조와 그래프 로딩, 연결 판정, 최단거리 계산 로직을 설계하고 구현했습니다.
  • 약 200개 규모의 초기 단어 풀을 여러 단계로 줄이고, 20~80개 노드 버전의 그래프 데이터를 제작했습니다.
  • 노드 수, 엣지 수, 최소·평균 차수와 실제 드로우 환경의 경로 성립 가능성을 함께 분석했습니다.
  • 플레이 테스트를 기반으로 애매한 관계를 삭제하고 저차수 노드와 주제군 사이의 연결을 보강했습니다.
  • 정답과 오답을 직접 시도하며 규칙을 익히는 튜토리얼의 학습 흐름을 기획하고 구현했습니다.
  • 팀원이 기획한 나레이터를 CSV 기반 대사, 우선순위, 거리·반복 실패 분기를 갖춘 런타임 시스템으로 구현했습니다.

설계 과정

처음에는 Emoji2Vec과 Word2Vec의 코사인 유사도로 관계를 생성하려 했습니다. 그러나 이 게임에 필요한 관계는 사자-호랑이 같은 유사어뿐 아니라 토끼-당근, 열쇠-문처럼 용도, 역할, 장소와 문화적 연상까지 포함했습니다. 임베딩 유사도만으로는 이런 관계를 일관되게 잡기 어려웠습니다.

이후 LLM으로 관계 후보를 넓게 생성하고 사람이 직접 검수하는 방식으로 전환했습니다. 특수한 상황을 추가하지 않아도 다수가 비슷한 장면을 떠올릴 수 있는지를 기준으로 삼고, 너무 구체적이거나 특정 분야 안에서만 작은 클러스터를 만드는 단어는 제거했습니다.

핵심 문제와 해결

초기 그래프는 전체 기준으로 연결되어 있었지만, 실제 플레이에서는 경로에 필요한 카드가 손패에 동시에 들어와야 했습니다. 즉 전체 그래프에 경로가 있어도 플레이어가 뽑은 카드로 만든 부분 그래프는 자주 끊겼습니다.

이를 해결하기 위해 노드 수만 줄이는 대신 저차수 노드를 우선 보강하고, 여러 주제군을 연결하는 중간 개념과 허브 단어를 배치해 최소 차수를 약 8~9 수준으로 높였습니다. 처음에는 엣지가 많으면 너무 쉬워질 것을 우려했지만, 실제 테스트에서는 경로의 존재와 경로의 발견이 다르다는 것을 확인했습니다.

결과적으로 그래프의 통계만이 아니라 플레이어가 관계를 즉시 납득할 수 있는지, 손패 안에서 선택지가 고르게 분포하는지를 함께 보며 데이터를 반복적으로 조정했습니다.
